# 「林间布语」视觉语言

## 核心气质

作品像一段被缝进旧棉布里的安静记忆：轻、暖、自然、有一点笨拙，但不幼稚。画面应让人想到晒过太阳的亚麻、抽屉里攒下的碎布和缓慢手缝的时间。

## 材质

- 底布：未漂白亚麻、原色棉、带细小棉籽点的米白粗纺布。
- 贴布：洗旧棉布、薄亚麻、青年布、细格纹、窄条纹、针点纹、褪色小花布。
- 表面：清楚可见经纬织纹，贴布略有厚度；边缘为手剪的轻微不齐，可有极少量自然毛边。
- 缝制：主要使用对比色锁边针或包缝针，针距近似但不机械统一；必要时用短平针画出枝梗、路线、雨点等细线。
- 所有布片都要像真实贴在底布上，有轻微压痕、起伏和接触阴影。

避免毛毡、摇粒绒、厚重棉絮、塑料亮片和大面积立体填充。不要让成品像机器刺绣徽章或无缝数码印花。

## 色盘

以 4–6 种布色加 1–2 种线色为宜。

- 基底：燕麦米、奶油白、浅亚麻色。
- 植物：鼠尾草绿、苔藓绿、灰橄榄绿。
- 天空与水：雾蓝、洗旧牛仔蓝、灰青色。
- 温暖强调：陶土红、莓果红、芥末黄。
- 柔和点缀：烟紫、藕粉、褪色珊瑚色。
- 针线：奶白、靛蓝、天蓝、芥末黄或暗红；与贴布形成清楚但不刺眼的对比。

避免荧光色、糖果色全套并用、纯黑大色块、过度复古的黄褐滤镜。色彩要像被洗过几次的布，柔和但仍清爽。

## 造型

- 用 2–5 块大布片概括一个主体，再用少量小布片或针线补充识别特征。
- 轮廓圆润、略不对称，保留手剪感；不要追求几何完美或复杂写实细节。
- 可爱来自比例和动作：小身体、大叶片、微微歪斜的月亮、走错半步的小羊；不要依赖大眼睛和夸张表情。
- 场景中最多设置一个视觉主角和两到四个陪衬元素。

## 构图

- 单幅作品保留约 35%–55% 的呼吸留白。
- 默认采用平静的不对称平衡，元素之间像有一条看不见的小路相连。
- 小样集合可放 4–7 个独立图形，但要统一尺度与间距；叙事场景控制在 1–3 个主体。
- 不用相框、胶带、贴纸阴影、撕纸边、手帐网格或屏幕 UI 冒充布艺。

## 成品摄影

- 默认柔和窗边日光，色温中性略暖。
- 采用俯拍或 15–30 度轻斜俯拍，让布面与针脚都清楚。
- 背景简洁，可见整块作品的自然边缘；不出现手机播放器、电脑、手或凌乱工作台，除非用户明确要制作过程照。
- 保留轻微皱褶和真实阴影，但画面干净、不脏旧。

## 必须排除

纸张拼贴、胶带拼贴、水彩、厚涂、平滑矢量图、CGI 塑料感、毛毡玩具感、机器绣花感、过度对称、密集装饰、高饱和儿童插画、随机英文、品牌标志、水印，以及对任何参考作品具体构图的复制。
